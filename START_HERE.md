# REMIXORA AI

The app is in `remixora-ai` and is running locally at **http://127.0.0.1:8000**.

To start it again:

```powershell
cd remixora-ai
.\run-local.ps1 -Background
```

Read `remixora-ai/README.md` for features and limits, `IMPLEMENTATION_PLAN.md` for the plan, `TEST_REPORT.md` for the 21 passing tests and browser evidence, and `DEPLOYMENT.md` for setup, optional authentication and backups.

The included demo is labeled synthetic narration. The default local mode uses heuristic scouting and template copy; optional model providers and automatic transcription are not configured. No cloud deployment or external publishing occurred.
